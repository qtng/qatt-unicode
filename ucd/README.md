# Draft character data

Draft Unicode Character Database entries for the proposal, generated by `tools/make_ucd.py` from `tools/qatt_grammar.py`. Run `python tools/make_ucd.py` after any change to names, offsets or properties.

| File | Content |
| --- | --- |
| UnicodeData-draft.txt | One line per character in the UnicodeData.txt format: name, General_Category, combining class, Bidi_Class |
| Properties-draft.txt | Grapheme_Cluster_Break, Indic_Conjunct_Break, Line_Break, East_Asian_Width, Vertical_Orientation, Script, Block |
| NamesList-draft.txt | Names list for the code chart, with annotations: source names of the Cán Tự and the tone of each tone mark |
| questions.md | Open questions for the Unicode text-segmentation and properties experts |

Code points are provisional: the block base U+F0000 (Supplementary Private Use Area-A) stands in for the position the UTC will assign. Only the offsets within the block come from the proposal. Where the proposal marks a value \[TBD\], the files contain the most likely value; questions.md lists each of them.
